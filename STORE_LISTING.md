# Chrome Web Store Listing

## Name
Block AI Overview

## Short Description (132 char max)
One-click toggle to block AI Overviews from Google search results. Get clean, classic links.

## Detailed Description
The robot stops here.

Block AI Overview adds a single query parameter (udm=14) to your Google searches, telling Google to show classic web results — no AI-generated summaries, no AI Overview panel. Just the links you came for.

HOW IT WORKS
• Toggle ON: Every Google search automatically gets &udm=14 appended, giving you clean web results
• Toggle OFF: Google behaves as normal with AI Overviews enabled
• Works instantly — no page reload needed for new searches

FEATURES
✓ One-click toggle in the toolbar
✓ Works on all Google country domains (google.com, google.co.uk, google.de, etc.)
✓ Minimal permissions — only accesses Google Search URLs
✓ No data collection, no tracking, no analytics
✓ Lightweight — runs at the network level with zero performance impact
✓ Setting syncs across your Chrome browsers

PRIVACY
This extension collects absolutely no data. The only thing stored is your on/off preference, saved locally in Chrome. No network requests are made. Full privacy policy available in the extension.
